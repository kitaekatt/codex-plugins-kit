Thin Codex adapter over the canonical llm-scripting-kit library for LLM delegation

The plugins directory holds the Codex plugins this repository ships, and this page covers the LLM delegation one. That plugin adapts the canonical llm-scripting-kit library so Codex can hand a bounded prompt or review to a configured LLM endpoint or CLI harness. It is deliberately thin: no library code and no endpoint configuration ship with it, because endpoint discovery, model resolution, credentials, harness dispatch, and error classification all belong to the llm-scripting-kit CLI in the shared runtime. What remains here is small on purpose -- a plugin manifest, one skill with a written-out workflow, and the agent metadata that exposes the skill to Codex.

Where to start

Start with llm-scripting-kit/skills/llm-delegate/SKILL.md: it is the only skill in the plugin and carries the full delegation workflow, from endpoint choice to exit-code triage. If the shared-runtime CLI is missing, that file also says which repository setup script installs it.

Routes

  • Delegate a prompt: endpoints -> models --endpoint NAME -> complete --endpoint NAME --model MODEL --format json, with the prompt on stdin; the answer is at response.text.
  • Check the backend without executing it: models --endpoint NAME -> resolve.
  • After a failed run: exit code 2 means correct the endpoint or model request and retry, exit code 3 is a persistent halt to report with its classified cause, and exit code 1 is an execution failure.

The delegation skill

  • llm-scripting-kit/skills/llm-delegate/SKILL.md -- the workflow end to end: which subcommands to call, when to prefer native Codex background agents over the CLI harness, and what the three exit codes mean. Open it before changing how work gets delegated.

Metadata for Codex

  • llm-scripting-kit/.codex-plugin/plugin.json -- the plugin manifest: name, version, the skills path, and the display text Codex shows for the plugin. Open it when the plugin's name, version, or description changes.
  • llm-scripting-kit/skills/llm-delegate/agents/openai.yaml -- the display name, short description, and default prompt for the delegate agent. Open it when the wording Codex users see should change.
