Codex plugin that adapts the Awesome Kit orchestrate and task skills

Plugins here make two Awesome Kit capabilities usable inside Codex: delegated orchestration of larger work and file-backed project tasks. The directory is small because it is an adapter: it points to the canonical task system instead of duplicating task behavior. The plugin manifest advertises the two skills, while each skill directory carries its operating instructions and an agent display file. The task launcher converts Claude-style skill calls into Codex-native calls when task work is emitted.

Where to start

Open .codex-plugin/plugin.json first to see what the plugin advertises, then open skills/task/SKILL.md for task management or skills/orchestrate/SKILL.md for delegated work.

Routes

  • Manage a task folder: read skills/task/SKILL.md, then run scripts/task.py with the canonical verb.
  • Prepare delegated work: read skills/orchestrate/SKILL.md, then use skills/orchestrate/references/delegation.md for the brief and verification rules.

Plugin identity

  • .codex-plugin/plugin.json -- the plugin manifest; open it to see the advertised name, version, skills path, and interface prompt.

Task adapter

  • skills/task/SKILL.md -- the task skill contract; open it when creating, working, updating, closing, or summarizing file-backed tasks. The upstream task implementation remains authoritative, so behavior questions go outside this directory.
  • scripts/task.py -- the Codex launcher; open it to see how the canonical task CLI is resolved and how work output is converted.
  • skills/task/agents/openai.yaml -- the agent display metadata for the task skill; open it when checking the short prompt shown to the agent.

Orchestration skill

  • skills/orchestrate/SKILL.md -- the orchestration contract; open it when deciding whether to delegate, how to brief a unit, or how to route it to a Codex agent or configured backend.
  • skills/orchestrate/references/delegation.md -- the delegation rules; open it to check brief content, file ownership, verification, and disagreement handling.
  • skills/orchestrate/agents/openai.yaml -- the agent display metadata for orchestration; open it when checking the short prompt shown to the agent.
